# Hansika — Freelance Web Developer Portfolio

A responsive, single-page portfolio built with HTML, CSS and vanilla JavaScript.

## Files
- `index.html` — page content and sections
- `style.css` — black-and-cyan premium styling and responsive layouts
- `script.js` — mobile navigation, current year and copy-email interaction

## Before publishing
1. Open `index.html`.
2. Replace `YOUR_EMAIL@example.com` in the contact section with your real professional email (both the visible text and `mailto:` address).
3. Replace the generic LinkedIn and GitHub profile URLs with your own profile URLs.
4. Add any additional project links or screenshots you want to showcase.
5. Check the project descriptions carefully and keep only work you can confidently explain.

## Preview locally
Open `index.html` in a browser.

## Publish free with GitHub Pages
1. Create a new public GitHub repository, for example `hansika-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. After deployment, GitHub will show your public website URL.

No build tools or paid hosting are required. Google Fonts are loaded from the web; the site still uses fallback fonts if they are unavailable.
